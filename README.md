# 光と反対色ラボ

赤・緑・青の光を重ねて、錐体の反応から反対色チャンネル、最終的な色の見え方までを、動かしながら確かめられる学習用のWebページです。色彩検定 UC級の学習を想定しています。

公開ページ: https://junhongo-ccs.github.io/mix_color/

## できること

ページは、教科書の「色情報への変換」の図と同じ流れで、左から右へ4つのステップに分かれています。

1. **光を重ねる（加法混色）**
   黒いステージの上で赤・緑・青の光の円を重ねます。円と観察点（白い照準）はドラッグで動かせます。光の強さはスライダーで変えられます。
2. **水晶体を通り、錐体が反応する**
   観察点の光に対する L・M・S 錐体の反応を、棒グラフで表示します。
3. **反対色チャンネル**
   「赤－緑（L−M）」「明るさ（L＋M）」「黄－青（S−(L＋M)）」の3本のメーターと、「L ＞ M → 赤みが強くなる」のような判定文を表示します。
4. **色として見える**
   見えている色、呼ばれやすい色名（基本色彩語のどれに入るか）、色相・彩度・明度を表示します。色の円の上には、観察点の位置を示します。

あわせて、次の2つも切り替えられます。

- **色覚タイプ**: 3色覚、1型2色覚、2型2色覚、3型色覚
- **年齢（20〜80歳）**: 水晶体の黄変で青い光が網膜に届きにくくなる様子

ヘッダーの「このラボの読み解き」を押すと、試験で問われやすい点と、それをラボのどこで確かめられるかをまとめたカードが開きます。加法混色、黄の正体、段階説、三属性と色名、色覚の多様性、加齢と黄変を扱っています。

## 手元で動かす

外部ライブラリは使っていません。index.html だけで動きます。

```sh
python3 -m http.server 8000
```

上のコマンドを実行してから、ブラウザで http://127.0.0.1:8000/ を開きます。フォントとアイコンは Google Fonts から読み込むので、インターネット接続が必要です。

## モデルについて

学習用に単純化したモデルです。実際の見え方には個人差があります。

- **錐体反応**: 表示色（sRGB）を、Smith–Pokorny 系の行列で LMS に変換しています。白い光で L＝M＝S＝1 になるように正規化しています。
- **反対色チャンネル**: 明るさは (L＋M)/2、黄－青は S−(L＋M)/2 として計算しています。
- **色覚シミュレーション**: Viénot・Brettel・Mollon（1999）の近似を使っています。
- **加齢の効果**: 水晶体と黄斑色素による吸収の増加分を、20歳を基準にした L・M・S ごとの透過率（80歳で S が約4割）として入れた目安です。脳の順応はかけていません。
- **明度**: 明るさのチャンネルを CIE L* に換算して10で割った値です。マンセル値の目安で、厳密には一致しません。
- **色名の境目**: モニターの原色が期待どおりの名前になるように調整した、学習用の角度です。
